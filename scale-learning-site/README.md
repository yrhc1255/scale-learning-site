# 尺度探索站

11 頁可操作的「尺度」互動教學網站。依李老師於 2026 年 9 月 27 日的指示，由 11 頁完整草圖進入全站製作；2026 年 9 月 28 日加入 GitHub Pages 與 GAS 成績同步。

## 開啟與指令

**直接雙擊測試：**開啟上層的 `index.html`。此檔已內嵌程式及樣式，不需要啟動伺服器，可離線使用。圖片讀取旁邊的 `scale-learning-site/public/designs/`，請保留資料夾相對位置。檔案模式與 HTTP 預覽的瀏覽器儲存空間不同，兩者進度不會互通。

開發預覽：http://127.0.0.1:4173/（需啟動下列開發指令）。

```powershell
npm.cmd install
npm.cmd run dev -- --port 4173
npm.cmd run build
npm.cmd run build:standalone
npm.cmd test
npm.cmd run test:e2e
```

瀏覽器測試使用已安裝的 Microsoft Edge。先啟動開發伺服器，再執行 `test:e2e`。本次交付為最外層的 `index.html`；修改程式後，執行 `build:standalone` 更新它。Vite 的 `build` 目前在模組轉換後無訊息結束，`dist/` 不作為本次交付入口，詳見驗證紀錄。

## 計分與保存

- 一般練習：第 1／2／3 次起答對分別為 3／2／1 分，最多 75 分；答錯不扣分，答對後不可重複加分。
- 形成性：首次提交成績，10 題全部作答後才能送出。學生看分數、薄弱概念與回顧入口；教師可在本機預覽看答案。
- 尺度快判：每題答對 30 分、錯誤不扣分，9 題滿分 270。保留最近一局與最佳分，成果頁呈現最近一局。
- 極限挑戰：沿用速度計分公式 `max(500, floor(5000 - position * 45))`。錯誤／逾時扣 1,000 分及 1 次生命，最低 0 分；3 次失誤或完成題庫結束。保留首次與最高分，成果頁及排行榜用最高分。
- 挑戰每題設定為 `max(14000, 22000 - 題序 * 350)` 毫秒；目前 19 題範圍約 16–22 秒。解析不計時，可暫停，切換視窗自動暫停；閱讀時間屬第四階段可供試用調整的設計參數。
- 本機儲存鍵為 `scale-learning-v4`，包含場次、身分、進度、嘗試紀錄與分開的成績。未提交的選項只保存在元件記憶體，重整即清除；嘗試次數和正式分數保留。
- 更改班級、座號、姓名即建立新場次；重新學習不覆寫舊場次。原紀錄只留在此瀏覽器，不會傳到外部服務。

## 教師檢查

左上角「教師模式」輸入 `55688` 進入本機預覽。預覽題目時使用獨立暫存場次，不改寫學生紀錄。可依班級、場次與主題查看本機資料、作答正確率、常見錯答、教師答案，以及匯出 CSV。匯出值已處理 CSV 引號與試算表公式注入。

這個密碼是原規格指定的本機便利入口，不提供正式帳號認證或雲端存取控制。前端題庫可被檢查，因此不宣稱其答案受到正式權限保護。

## 視覺與教材來源

- 教材：上層 `03-115國中自然1上備課尺度.pdf`，課本第 52 至 61 頁及教學指引。

- 保留米白／深海藍／青綠、觀察手冊、單排進度列、自然圖像、量測工作臺、顯微鏡、分類槽及深色挑戰區等設計。圖片以 SVG 視窗顯示指定圖像區域，不直接把草圖當作整頁網站。
- 操作所需的比例尺、生物結構、尺度物件與動畫以原創 SVG／CSS 重建。比例尺有真實的幾何比值；構造插圖及光學模擬均標為示意。生成圖像不是顯微實拍，也不能用作螢幕物理長度校準。
- 字型使用系統可用字型，無外部字型、照片或影片載入需求。

## 階段界線

本版為第四階段：全部 11 頁先開放，完成狀態正常記錄，供老師自由巡覽。尚未啟用正式逐頁鎖定。

網站發布於 GitHub Pages，成績摘要同步至專案擁有者的 Google Apps Script 與試算表。前端使用本機佇列，寫入成功後才移除待傳資料；同一事件重送時由 GAS 去重。公開程式庫只包含 GAS 網頁應用程式網址，不包含試算表網址、帳號或 ID。

Firebase 與 Firestore 沒有建立或連接。學生完整作答歷程仍只保存在目前瀏覽器；GAS 接收成績摘要，不提供跨裝置續學。教師模式密碼仍只是前端預覽入口，不是 Google 試算表的存取權限。
